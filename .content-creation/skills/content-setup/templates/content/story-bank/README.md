# Story bank

Real stories the skills can use as proof. A story makes a payload believable; it's never the whole post.

- `mine/`: things that happened to you.
- `borrowed/`: stories from other people (books, interviews, articles, friends who said yes). Always credited, never told as if they happened to you.

This folder is optional. Without it, skills ask you for a story or leave a `[placeholder]`. They never make one up.

---

## How skills use it

1. Read the index below. Match on **themes** and **what it proves**, not just the title.
2. Open only the two or three story files that fit. Never load the whole folder.
3. Use the story's specifics (the moment, the line). Don't sand it into a generic anecdote.
4. Never add details that aren't in the file. If a story is close but missing a detail, ask.
5. After you approve a piece that used a story, add it to that story's `used-in` list, so you can see what's been told and where.
6. If no story fits, say so and suggest what kind of story would. Never invent an event.

## How to add a story

Copy `_template.md` into `mine/` or `borrowed/`. Name it `YYYY-short-slug.md` (the year it happened, or the year you heard it for borrowed ones), then add a row to the index. A rough story is fine to start.
