# Platforms: captions for Instagram Reels, TikTok and YouTube Shorts

Checked against official help docs, November 2026. Platforms change these often.

The caption method is the same on all three: CTA first, a setup line, the layer the video didn't cover, then a plain-text keyword line. What changes is the limit, what sits on screen with the caption, and what the CTA can promise.

## Limits

| | Caption limit | Notes |
| - | - | - |
| Instagram Reels | 2,200 characters | The caption is cut off after a short preview, so line 1 is the only line everyone sees. |
| TikTok | about 4,000 characters in the app | Widely reported, not officially documented. Posts sent through scheduling tools are capped at 2,200, so stay under 2,200 if the user schedules. |
| YouTube Shorts | title 100 characters, description 5,000 characters | The title shows over the video in the Shorts player. |

The archetypes in this skill run well under every limit. If a caption is getting close, cut items, not line breaks.

## Instagram Reels

- **What sits next to the caption:** the cover frame and the first line of the caption. The CTA goes in that first line.
- **Comment-keyword CTA:** "Comment [KEYWORD] and I'll send it to you" works when the user has a way to send DMs automatically when someone comments. Check that they do before promising it.
- **What it rewards:** Instagram has said sends (shares by DM) and watch time are among its strongest signals for reaching new people. A caption worth saving or sending supports both.

## TikTok

- **Search:** people use TikTok as a search engine. The keyword line and the topic's words near the top of the caption do the most work here.
- **CTA:** the comment-keyword CTA works for engagement, but automatic DMs on TikTok are more limited (check the user's setup). If DMs aren't set up, point to the link in bio instead.

## YouTube Shorts

- **Title:** treat it as a second visual hook: short, specific, the same promise as the video, with the topic's search words up front. 100 characters max.
- **Description:** the caption body and keyword line.
- **Links:** links in Shorts descriptions and comments aren't clickable. Swap "comment for the link" for "the full walkthrough is on my channel", or link a related long video to the Short.

## Posting one video to all three

- Keep the body and keyword line identical; adapt the CTA per platform (above).
- Write a separate Shorts title; don't paste the Instagram first line into it.
- Upload a clean file to each platform, never a download with another platform's watermark.
