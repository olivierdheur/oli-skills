# Button markers, CTA suggestions and the paywall

Substack buttons and the paywall are native blocks in the editor. A Markdown draft can only mark where they go; the user inserts the real blocks when pasting the article in. X Articles have no equivalent, so drop all markers from an X version.

## The four markers

Only these compact markers belong inside the copy-ready article, each on its own line with a blank line above and below:

| Marker | Where |
|---|---|
| `[[SUBSCRIBE: TOP]]` | After the opening and **Here's what we cover**, before the first substantive section |
| `[[SHARE: MIDDLE]]` | Near 40% of the body, at an existing section boundary |
| `[[SUBSCRIBE: UPGRADE]]` | Near 70%, at an existing section boundary. Subscribe for a free issue, upgrade for a paid one |
| `[[SHARE: END]]` | After the final reflection, before the footer |

- Use the nearest real boundary rather than splitting a thought. The percentages are guides, not rules.
- Never put two markers next to each other. If two land together, move one to another boundary.
- The marker text is fixed syntax, not article prose.
- On a repeat pass, move existing markers instead of adding new ones.

## Suggested button lines (publishing notes only)

Give one short suggested line per marker, separate from the article and clearly labeled. Don't leave blank "your line here" slots.

- **Subscribe lines** name the real recurring benefit and cadence from the user's details. Never invent a benefit, a schedule or a paid offer.
- **Share lines** name a specific person who would benefit ("Know a founder still writing every post by hand? Send them this.").
- Pull language from the article where you can.
- CTA copy the user already approved stays as it is, in the body if that's where they put it.

## Paywall (conditional)

Use `[[PAYWALL]]` only when the user asks for a paid section or the issue contains distinct paid material (a template, a full walkthrough, a dataset). If there's no distinct paid artifact, recommend keeping the issue free. If the decision is open, keep the body free and propose the cutoff in the notes instead of placing the marker.

When a cutoff is used:
- Place it after a self-contained free introduction and real substance, right before the paid material. There's no fixed percentage.
- Keep it away from the other markers.
- Put most of the user's own links above it.

In the notes only, show:
1. A suggested teaser line that names what the paid section actually delivers.
2. The last 2–3 lines free readers see, quoted from the body.
3. The first 2–3 lines behind the cutoff, quoted from the body.

Don't duplicate these excerpts inside the article.
