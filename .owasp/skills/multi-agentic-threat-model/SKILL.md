# Multi-Agentic Threat Model

Threat-model multi-agent systems using CSA MAESTRO.

## When to Use

Say: "Model threats for this multi-agent system"

## What It Does

- Threat models multi-agent AI systems
- Uses CSA MAESTRO 7-layer framework
- Identifies cross-agent attack vectors
- Maps trust boundaries

## References

- CSA MAESTRO Framework (7 layers)
- OWASP Multi-Agentic System Guide v1.0

## MAESTRO Layers

1. **Foundation**: Infrastructure and runtime
2. **Data**: Data flows and storage
3. **Model**: LLM and ML models
4. **Agent**: Individual agent behavior
5. **Orchestration**: Agent coordination
6. **Interface**: External interactions
7. **Ecosystem**: Multi-system integration

## Output Format

- Layer analyzed
- Threat identified
- Attack vector
- Trust boundary affected
- Risk level
- Mitigation controls
