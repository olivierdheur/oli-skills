# Prompt Injection Testing

Test for prompt injection using Arcanum PI Taxonomy.

## When to Use

Say: "Test for prompt injection"

## What It Does

- Tests LLM apps against prompt injection attacks
- Uses Arcanum PI Taxonomy framework
- Covers 18 attack techniques
- Tests 20 evasion methods
- Evaluates 13 attack intents

## OWASP References

- LLM01: Prompt Injection
- Arcanum PI Taxonomy (CC BY 4.0)

## Attack Taxonomy

- **Techniques** (18): Direct injection, indirect injection, payload delivery methods
- **Evasions** (20): Encoding, obfuscation, context manipulation
- **Intents** (13): Data exfiltration, privilege escalation, denial of service

## Output Format

- Attack technique used
- Evasion method tested
- Result (success/failure)
- System response analysis
- Vulnerability assessment
- Mitigation recommendations
