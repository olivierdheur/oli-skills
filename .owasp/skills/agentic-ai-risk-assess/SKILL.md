# Agentic AI Risk Assessment

Assess agentic AI applications against Top 10 Agentic 2026.

## When to Use

Say: "Assess agentic AI risks"

## What It Does

- Assesses autonomous agent applications
- Evaluates agent decision-making risks
- Reviews tool access and permissions
- Identifies multi-agent coordination issues

## OWASP References

- OWASP Top 10 for Agentic Applications 2026
- OWASP Agentic Security Initiative
- OWASP Multi-Agentic System Guide v1.0

## Risk Categories

- Excessive autonomy
- Inadequate oversight
- Tool permission escalation
- Agent impersonation
- Cross-agent attacks
- State manipulation
- Goal hijacking
- Resource exhaustion

## Output Format

- Risk category
- Severity assessment
- Attack vector
- Impact analysis
- Recommended controls
