# API Security Review

API review against OWASP API Security Top 10 (2023).

## When to Use

Say: "Review this API for security"

## What It Does

- Reviews API endpoints for security vulnerabilities
- Checks authentication and authorization
- Assesses rate limiting and resource consumption
- Identifies data exposure risks

## OWASP References

- OWASP API Security Top 10 (2023)
  - API1: Broken Object Level Authorization
  - API2: Broken Authentication
  - API3: Broken Object Property Level Authorization
  - API4: Unrestricted Resource Consumption
  - API5: Broken Function Level Authorization
  - API6: Unrestricted Access to Sensitive Business Flows
  - API7: Server Side Request Forgery
  - API8: Security Misconfiguration
  - API9: Improper Inventory Management
  - API10: Unsafe Consumption of APIs

## Output Format

- API endpoint analyzed
- Vulnerability category
- Risk assessment
- Evidence
- Remediation recommendations
