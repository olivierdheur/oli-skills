# Valuation Check

Use this skill to inspect a valuation, not to provide personalized investment
advice.

## Workflow

1. Identify valuation method, time horizon, assumptions, and source data.
2. Check revenue, margin, working capital, capex, discount rate, terminal value,
   multiples, and share count.
3. Run sensitivity and downside cases.
4. Flag assumptions that dominate the output.

## Output

Return `Valuation summary`, `Assumption audit`, `Sensitivity ideas`, `Sanity
checks`, and `Questions for diligence`.
